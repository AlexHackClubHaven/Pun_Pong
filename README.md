# Pun Pong


NOTE! The browser version will be a bit too far zoomed in when you open it, so zoom out the page to see the full gamespace!

Have you ever wanted to punch a floating clown face so hard that you start playing pong with it? No? Too bad.

Defeat the clown to win!


CONTROLS:
Left Click on the clown to start
Up and down arrow keys to control paddles
Space when game over to restart
